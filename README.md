# Hyperbros

An original side-scrolling platformer in a single HTML file — no build step, no dependencies.

Play: open `index.html` in a browser (or serve the folder with any static server).

## Controls
| Action | Keyboard | Touch |
|---|---|---|
| Move | ← → / A D | ◀ ▶ |
| Jump (hold for higher) | Space / ↑ / W / Z | ⤒ |
| Run | Shift / X | R |
| Start | Enter | tap |

## Cast
- **Hyper** — goggled runner with a trailing yellow scarf.
- **Hyper Cell** — pink battery from glowing ◆ blocks; makes Hyper tall and able to smash bricks. Taking a hit shrinks you back.
- **Grumblers** — grumpy purple blobs. Stomp them.
- **Spikebacks** — red-shelled beetles. Stomp to turn them into a shell, then kick it into other enemies.
- **Gems** — collect 100 for an extra life.

Reach the swirling portal at the end of Zone 1 before time runs out. There's a checkpoint halfway.
